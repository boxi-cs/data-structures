# Data Structures

Interactive notes, step-through demos, videos and exercises for a university Data Structures course, in Python and in Java.

- Site: https://boxi-cs.github.io/data-structures/
- Instructors: Boxi Yu ([boxiyu.github.io](https://boxiyu.github.io/)) and Yintong Huo ([yintonghuo.github.io](https://yintonghuo.github.io/))
- Interactive notes and videos powered by [培玉智能](https://www.peiyuzhineng.com/).

This repository holds the built site (static files). Chapters are added as they are finished.
